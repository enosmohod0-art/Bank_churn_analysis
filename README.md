Bank Customer Churn Analysis
📌 Project Overview

This project focuses on analyzing customer churn behavior in a bank using Python.
The goal is to identify key factors that influence whether a customer stays with the bank or exits, and to translate those findings into actionable business insights.

The project follows a data analytics approach (not machine learning) and emphasizes:
Data understanding
Exploratory Data Analysis (EDA)
Visualization
Business interpretation

🎯 Objective

Understand overall customer churn rate
Identify customer segments with higher churn risk
Support business teams with insights to improve customer retention

📊 Key Insights

The analysis explores churn patterns across multiple dimensions:
Overall churn distribution
Gender-wise churn analysis
Geography-wise churn comparison
Age group–wise churn trends
Customer activity status vs churn
Number of products vs churn
Account balance behavior vs churn

Each insight is supported by visualizations and clear business interpretation.
